# EE538 Projects
This repository contains coursework completed for EE538: Computing Principles for 
Electrical Engineers. The work is organized into separate folders for the lab, homework assignments, 
midterm, and final project. Each folder contains its own source code, supporting files, tests, 
and assignment-specific README when available.
